# MinELE 2026 — Mining & Environmental Laws and Ethics
## GitHub Pages Update — October 2026

This package updates the existing static reviewer without introducing a backend.

### New modes
- TOPICS
- WHO REGULATES?
- WHICH LAW APPLIES?

### Question-bank QC
Existing section-number clues in question stems were removed where they acted as answer cues.
New integrated questions use close regulatory distractors and optional distractor-by-distractor explanations.
Question references may still show provision/source metadata after answering.

### GitHub Pages
Replace your repository's existing `index.html` with the new `index.html` from this package.
No build step, Node, PHP, Python server, SQL database or API key is required.

### Progress
The reviewer keeps localStorage progress. Replacing the HTML file normally preserves progress in the same browser/site origin.
